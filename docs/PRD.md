# 사이트 설계도(PRD) — (미정: 사이트 이름)

작성일: 2026-11-15 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
병원·학원의 블로그 글을 대신 써 주는 블로그 마케팅 대행.

## 2. 손님
- 누가: 병원·학원 같은 전문업 원장님 (블로그 마케팅을 맡길 곳을 찾는 분)
- 어디서 알고 오나: 네이버 검색, 내 블로그·인스타

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 비용 — 한 달에 얼마인지
2. 글 예시·진행 방식 — 어떤 글을, 어떤 순서로 써 주는지
3. (미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 직접 쓴 글 샘플
- 내 블로그 운영 자체 (내 블로그·인스타 링크)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 무료 상담 신청
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + [무료 상담 신청] 버튼
2. 이렇게 진행해요 — 상담 → 글 방향 정하기 → 글 작성 → 확인·발행 (실제 순서는 만들 때 사용자 확인)
3. 직접 쓴 글 샘플 + 내 블로그·인스타 바로 가기
4. 비용 안내 — 가격 (미정) → "상담 후 안내"로 표시
5. 후기 자리 (비워 둠)
6. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 업종 (병원 / 학원 / 기타)
- 운영 중인 블로그 주소
- 궁금한 점 (자유 글)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정) — 사이트에는 "상담 후 안내"
- 시간: (미정)
- 위치: (미정) — 온라인 진행이면 적지 않아도 됨
- 연락 방법: 사이트 문의 폼만 (전화·카톡·이메일은 넣지 않음)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인 (다음에)
- 결제
- 사진·파일 올리기
- 알림 메일
- 전화·카카오톡·이메일 연락 버튼

## 10. 첫 화면 한 문장 후보
1. 원장님은 진료·수업에 집중하세요. 블로그 글은 제가 대신 씁니다.
2. 병원·학원 블로그, 매달 꾸준히 대신 써 드립니다.
3. 검색하는 환자·학부모에게 닿는 블로그 글, 대신 써 드려요.

## 11. 다음에 할 것
- 사이트 이름 정하기
- 가격(한 달 비용) 정하기
- 실제 고객 후기 모이면 후기 자리 채우기
- 궁금한 것 세 번째 항목 정하기
- 의료·교육 광고 규정 안내를 넣을지 정하기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
